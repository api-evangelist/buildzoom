# BuildZoom

> BuildZoom connects homeowners and property owners with vetted local general contractors, and operates the Building Permit Database (buildzoomdata.com) — a normalized dataset of 350M+ building permits across 25+ years, 2,400 jurisdictions, and 90% of the US population, plus 6M+ licensed contractors. The data is delivered via bulk exports, a RESTful Data API (batch requests, sub-second latency), a Data Explorer web app, and a Permit Map. Backed by a16z and Y Combinator.

## APIs

- [BuildZoom Data API](https://www.buildzoomdata.com/): RESTful API over the Building Permit Database — property permit history and contractor license/permit lookups, batch requests, sub-second latency. Base URL: https://api.buildzoomdata.com (access and developer docs gated behind a buildzoomdata.com account).

## Products

- [Building Permit Database](https://www.buildzoomdata.com/): The permit data product surface (Bulk Data, Data API, Data Explorer, Permit Map).
- [Permit Map](https://www.buildzoomdata.com/map): Address-based property permit history search.
- [BuildZoom Marketplace](https://www.buildzoom.com/): Contractor matching and hiring for property owners.
